# Taller — versión Firebase + GitHub

Suba TODO el contenido de esta carpeta a la raíz del repositorio de GitHub (incluida la carpeta `icons`).

| Archivo | Para qué sirve | ¿Lo edito? |
|---|---|---|
| `index.html` | La aplicación completa | No |
| `firebase-config.js` | Los datos de SU proyecto Firebase | **Sí, una vez (paso 6 de la guía)** |
| `manifest.json`, `sw.js`, `icons/` | Instalarla como app y abrirla sin internet | No |
| `firestore.rules` | Reglas de seguridad para pegar en Firebase | **Sí: ponga sus correos (paso 4)** |

Para actualizar la app en el futuro suba solo el nuevo `index.html` (no toque `firebase-config.js`).
Siga la guía paso a paso que le entregó Claude.
